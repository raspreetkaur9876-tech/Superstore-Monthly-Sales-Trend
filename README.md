# Superstore Monthly Sales Trend Analysis

## Project Overview
This project analyzes monthly sales using the Superstore dataset in Microsoft Excel. It helps identify sales patterns and understand how sales change over time.

## Objectives
- Analyze monthly sales from 2014 to 2017.
- Calculate total sales for each month.
- Identify monthly sales trends.
- Present sales data using a line chart.

## Tools Used
- Microsoft Excel
- Superstore Dataset
- Excel Formulas
- Line Chart Visualization

## Project Steps
1. Downloaded the Superstore dataset.
2. Organized the data in Excel.
3. Created a Month column.
4. Calculated monthly total sales using Excel formulas.
5. Created a monthly sales summary.
6. Designed a line chart to visualize sales trends.

## Key Findings
- Monthly sales vary throughout the year.
- Some months show higher sales than others.
- The line chart makes it easier to compare monthly sales.
- The analysis helps understand sales performance over time.
